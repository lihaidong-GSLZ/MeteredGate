# Metered Gate 0.3.1 设计说明

## 1. 目标

Metered Gate 是按周期发放离散接收许可的 `1×1` 平面传送带节点：配额不累计、货物进入一件缓冲时扣除许可、多输出轮询，缺电和暂停时冻结。

## 2. 原型组合

```text
Flat Conveyor  -> 建造成本与默认建造优先级
Flat Connector -> EntityLayout + ports + Gfx + icon + placement range
MeteredGateProto -> LayoutEntityProto
```

不能继承 `MiniZipperProto`。该类型代表自动小连接器，会触发运输带切割、专用验证、自动生成和蓝图过滤。也没有理由继承 `ZipperProto`，因为本建筑不使用平衡器/分流器状态机。

## 3. 高度验证

允许范围来自：

```text
sourceConnector.Layout.PlacementHeightRange
```

`PlacementHeightRange` 会被原生放置器用于初始高度和升降输入，但对普通 `LayoutEntityProto` 并不是最终建造验证。0.3.1 因此注册：

```text
MeteredGateHeightValidator
  : IEntityAdditionValidator<LayoutEntityAddRequest>
```

验证器只处理 `MeteredGateProto`。它按照原版预览的计算方式求相对高度：

```text
relativeHeight = request.Transform.Position.Height
               - terrain[originTile].Height.TilesHeightRounded
```

然后要求：

```text
PlacementHeightRange.From <= relativeHeight <= PlacementHeightRange.To
```

范围外返回 `EntityValidationResult.CreateError`。该约束通过公开依赖注册 API 接入，不访问放置器私有字段或私有升降方法，也不使用 Harmony。单体放置、复制、蓝图和移动最终都必须通过实体添加验证器。

若请求原点已经在地图外，验证器返回 Success，让优先级更低、先执行的原生 Terrain validator 报告地图边界错误；这样在 call-all 模式下也不会越界访问地形数组。

## 4. 图形

Connector 的 `Gfx` 在初始化时绑定 owner，不能直接由两个 Proto 共享。代码使用 `MemberwiseClone` 复制配置，然后清空 `m_proto`、保留 Connector 图标路径，并将 `IconIsCustom` 设为 true。这是唯一保留的内部字段依赖。

## 5. 电力

原型实现 `IProtoWithPowerConsumption` 并声明 20 kW。实体实现 `IElectricityConsumingEntity`，由 `ElectricityConsumerFactory` 创建 consumer。每个有效模拟 tick 调用 `TryConsume(false)`；失败时周期和物流都不推进。通用 Priority 由原生观察者链处理。

## 6. 状态机

新建筑从空缓冲、零剩余配额和零周期相位开始。每个有电 tick 推进周期，跨周期时把剩余配额赋值为设定值。输入接收量为：

```text
accepted = min(offered, 1, remainingQuota)
```

## 7. 配置命令

Inspector 写操作通过 `InputCommand` 调度，只保存实体 ID、命令类型和整数值；模拟侧 processor 查找实体并应用。周期控制提供 `-30 s`、`-10 s`、`-1 s`、`+1 s`、`+10 s`、`+30 s` 六个步长，全部复用 `AdjustCycleSeconds` 命令，最终仍由实体侧夹紧到 1–3600 秒并重启当前周期。

## 8. 存档

v2 顺序：基类、版本 2、`ElectricityConsumer`、缓冲、剩余配额、周期相位、周期秒数、每周期数量、输出索引。

v1 没有 consumer。读取 v1 后注册 `InitPriority.Lowest` 的 after-load 回调，待 ElectricityManager 恢复完成后再创建 consumer。

## 10. 发布边界

0.3.1 验证目标为 CoI 0.8.6–0.8.6c。游戏升级后优先复核：

1. `IEntityAdditionValidator<LayoutEntityAddRequest>` 注册与调用；
2. `LayoutEntityAddRequest.Transform` 和地形高度计算；
3. `LayoutEntityProto.Gfx` 字段；
4. ElectricityConsumer 的序列化与初始化优先级；
5. Flat Connector 的布局和资源路径。

## 依赖注册

CoI 0.8.6 的 `DataOnlyMod.RegisterDependencies` 是 final 接口实现，不能 override。`MeteredGateMod` 重新声明 `IMod` 并显式实现 `IMod.RegisterDependencies`，用于注册高度验证器。
