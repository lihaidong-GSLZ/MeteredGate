# 设计说明

## 模组分层

- `MeteredGateMod`：模组入口，绑定配置并注册原型；
- `MeteredGateSettings`：读取新建筑的默认周期与配额；
- `MeteredGateData`：从原版 Flat Conveyor 推导对应的 Connector 与 Balancer 原型；
- `MeteredGateProto`：复用原版 1×1 布局、图形、动态端口与架高契约；
- `MeteredGateEntity`：处理周期、配额、单件缓冲、轮询输出和存档；
- `MeteredGateInspector`：显示周期、配额和状态，并提供参数按钮。

## 配额模型

一个周期结束时：

```text
remainingQuota = itemsPerCycle
```

而不是：

```text
remainingQuota += itemsPerCycle
```

因此未使用配额不会累积。

物品进入闸门时立即执行：

```text
buffer = 该物品
remainingQuota -= 1
```

这样“放行”对应的是物品离开上游，而不是下游最终接收成功。

## 单件缓冲

缓冲有物品时，所有输入均拒收。输出堵塞不会导致闸门继续从上游抽取物品，因此跨周期最多残留一个已经离开上游的单位。

## 输出路由

多个输出使用 round-robin：每次成功发送后，下次从下一个输出开始尝试。它不实现原版 Balancer 的优先级和均匀分配控制。

## 存档

运行状态保存：

- 缓冲物品；
- 剩余配额；
- 周期相位；
- 周期秒数；
- 每周期数量；
- 输出轮询位置。

复制/蓝图只复制周期秒数与每周期数量，不复制当前相位、实时额度或缓冲内容。
