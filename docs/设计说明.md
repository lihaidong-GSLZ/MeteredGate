# Metered Gate 0.3.0 设计说明

本文记录 0.3.0 的实际结构、状态机与兼容性边界。

## 1. 目标

Metered Gate 不是限速器，而是按周期发放离散“接收许可”的 1×1 平面传送带节点：

- 每栋建筑独立配置周期和配额；
- 配额不累计；
- 货物离开上游时扣除许可；
- 内部最多一件；
- 多输出轮询；
- 缺电和暂停时冻结。

## 2. 原型组合

```text
Flat Conveyor  -> 建造成本与默认建造优先级
Flat Connector -> EntityLayout + ports + Gfx + icon + placement range
MeteredGateProto -> LayoutEntityProto
```

不能继承 `MiniZipperProto`。该类型在游戏内部代表自动小连接器，会触发切开运输带、专用验证、自动生成和蓝图过滤。也没有理由继承 `ZipperProto`，因为本建筑不使用平衡器/分流器的原型或状态机。

## 3. 高度

高度合法范围来自：

```text
sourceConnector.Layout.PlacementHeightRange
```

原生放置器在选择原型时读取这一范围，并在最终放置验证中拒绝范围外位置。0.3.0 不再修补放置器私有字段和私有升降方法。

## 4. 图形

Connector 的 `Gfx` 在初始化时绑定 owner，不能直接由两个 Proto 共享。0.3.0 使用 `MemberwiseClone` 复制配置，然后：

- 清空 `m_proto`；
- 保留 Connector 图标路径；
- 将 `IconIsCustom` 设为 true，防止按 `MeteredGate_Entity` 生成不存在的图标路径。

这是唯一保留的内部字段依赖。

## 5. 电力

原型实现 `IProtoWithPowerConsumption` 并声明 20 kW。实体实现 `IElectricityConsumingEntity`，构造时由 `ElectricityConsumerFactory` 创建 consumer。

每个有效模拟 tick：

```text
hasPower = consumer.TryConsume(false)
```

若失败，周期和物流都不推进。通用 Priority 由 `LayoutEntity` 与 `ElectricityConsumer` 的原生观察者链处理。

## 6. 状态机

新建筑：

```text
buffer = empty
remainingQuota = 0
cycleElapsed = 0
```

每个有电 tick：

1. 周期增加一个 `Duration.OneTick`；
2. 跨界时 `remainingQuota = itemsPerCycle`；
3. 尝试将缓冲物发送到 round-robin 输出。

输入接收条件：启用、有电、缓冲为空、配额为正。实际接收：

```text
accepted = min(offered, 1, remainingQuota)
```

## 7. 配置命令

Inspector 的写操作必须进入 `InputCommand`，不直接写实体：

- 调整周期；
- 调整配额；
- 重启周期。

命令只保存实体 ID、命令类型和整数值，processor 在模拟侧查找实体并应用。

## 8. 存档

v2 顺序：

1. `LayoutEntity` 基类；
2. `SaveVersion = 2`；
3. `ElectricityConsumer`；
4. 缓冲；
5. 剩余配额；
6. 周期相位；
7. 周期秒数；
8. 每周期数量；
9. 输出索引。

v1 没有第 3 项。载入 v1 时，读取旧字段后注册 `InitPriority.Lowest` 回调，待 ElectricityManager 完成自身恢复后再创建 consumer。

## 9. 稳定身份

以下字符串进入仓库、加载或存档契约，不能随意改动：

```text
MeteredGate
MeteredGate.dll
MeteredGate.MeteredGateMod
MeteredGate_Entity
MeteredGate.CycleSeconds
MeteredGate.ItemsPerCycle
```

## 10. 发布边界

0.3.0 只验证目标为 CoI 0.8.6–0.8.6c。升级游戏版本时优先检查：

1. `LayoutEntityProto.Gfx` 字段；
2. `LayoutEntityProto` 构造函数；
3. `ElectricityConsumer` 序列化与初始化优先级；
4. Flat Connector 的布局和资源路径。
